# Word 模板规范（第一阶段）

## 适用范围

仅支持本仓库 `templates/` 中由本项目生成的规范化 `.docx`。不承诺兼容任意 Word 文件。模板由普通段落和文本运行组成；不支持浮动文本框、宏、嵌套表格、内容控件、字段代码、修订标记、外链图片或模板内计算公式。

## 占位符

采用大小写敏感的双花括号格式，每个占位符独占一个段落：

`{{name}}`、`{{email}}`、`{{phone}}`、`{{location}}`、`{{summary}}`、`{{education}}`、`{{work}}`、`{{projects}}`、`{{skills}}`、`{{certificates}}`。

重复经历使用一个模块占位符。填充器按岗位简历数组顺序生成条目，条目之间空一行；标题、机构、日期和要点来自结构化字段，不允许模板作者在占位符外复制用户事实。简介和要点内的换行保留为 Word 段落换行。

## 空模块与排序

没有条目的模块删除标题及占位符所在段落，不留下空标题或占位文字。条目顺序严格沿用生成 JSON 的数组顺序；程序不根据日期自行重排。

## 长内容与分页

使用 A4 页面、普通段落和 Word 自动分页。禁止固定行高、绝对定位和依赖单页高度的布局。长内容可以自然跨页；输出后须渲染 PDF 检查中文字体、换行、分页、重叠、截断和意外空白页。

## 字体与 PDF

模板指定中文字体“Hiragino Sans GB”；Windows 或其他系统缺少该字体时允许 Word/LibreOffice 使用“微软雅黑”或系统可用的中文 sans-serif 替代字体。当前导出器通过 LibreOffice `soffice --headless --convert-to pdf` 转换；缺少 LibreOffice 时给出明确错误，不以仅生成 DOCX 作为 PDF 成功。

## 填充后检查

输出必须通过 DOCX ZIP 完整性检查、不得残留 `{{...}}` 占位符，PDF 必须存在且大于零字节。人工验收还需实际渲染短、长和空模块样例，检查中文字体、换行、分页、重叠和截断。
